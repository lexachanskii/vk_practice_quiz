# QuizFlow

QuizFlow — веб-приложение для создания и проведения интерактивных квизов в реальном времени.

В приложении есть две роли: организатор и участник. Организатор создаёт квизы, добавляет вопросы, запускает комнату и управляет ходом игры. Участники подключаются по коду комнаты, отвечают на вопросы во время их показа и видят результаты.

- Добавление вопросов
- Вопросы с одним правильным ответом
- Вопросы с несколькими правильными ответами
- Текстовые вопросы
- Вопросы с изображениями
- Загрузка изображений для вопросов
- Создание комнаты для прохождения квиза
- Подключение участников по коду комнаты
- Отображение вопросов в реальном времени
- Серверный таймер для вопросов
- Отправка ответа только во время активного вопроса
- Автоматический подсчёт баллов
- Лидерборд в реальном времени
- Страница итоговых результатов
- История проведённых сессий у организатора
- История прохождений у участника

## Требования для запуска

Перед запуском должны быть установлены:

- Node.js
- npm
- Docker Desktop

## Переменные окружения

Перед запуском нужно создать `.env` файлы на основе примеров.

### Backend

Создайте файл:

```text
server/.env
```

Пример содержимого:

```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/quiz_app?schema=public"
JWT_SECRET="change_this_secret"
PORT=5000
CLIENT_URL="http://localhost:3000"
```

### Frontend

Создайте файл:

```text
client/.env.local
```

Пример содержимого:

```env
NEXT_PUBLIC_API_URL="http://localhost:5000"
```

## Запуск проекта

### 1. Запустить PostgreSQL

Из корня проекта выполните:

```bash
docker compose up -d
```

### 2. Запустить backend

Откройте терминал и выполните:

```bash
cd server
npm install
npx prisma generate
npx prisma migrate dev
npm run dev
```

Backend будет доступен по адресу:

```text
http://localhost:5000
```

### 3. Запустить frontend

Откройте второй терминал и выполните:

```bash
cd client
npm install
npm run dev
```

Frontend будет доступен по адресу:

```text
http://localhost:3000
```

## Основной сценарий использования

1. Зарегистрироваться как организатор.
2. Создать новый квиз.
3. Добавить вопросы и варианты ответов.
4. Запустить комнату для прохождения квиза.
5. Войти как участник в другом браузере или в режиме инкогнито.
6. Подключиться к комнате по коду.
7. Организатор начинает сессию.
8. Организатор показывает вопросы один за другим.
9. Участники отвечают на вопросы в реальном времени.
10. После завершения квиза открывается страница итоговых результатов.
11. Организатор может посмотреть историю проведённых сессий.
12. Участник может посмотреть историю своих прохождений.

## Работа с изображениями

Изображения, загруженные для вопросов, сохраняются локально в папке:

```text
server/public/uploads
```

Файлы изображений не добавляются в Git. В репозитории хранится только файл `.gitkeep`, чтобы папка существовала после клонирования проекта.

## Полезные команды

Сгенерировать Prisma Client:

```bash
cd server
npx prisma generate
```

Применить миграции:

```bash
cd server
npx prisma migrate dev
```

Открыть Prisma Studio:

```bash
cd server
npx prisma studio
```

Проверить сборку backend:

```bash
cd server
npm run build
```

Проверить сборку frontend:

```bash
cd client
npm run build
```
