# Quiz App

Веб-приложение для проведения квизов в реальном времени.

# Стек

- Frontend: Next.js / React
- Backend: Node.js + Express + TypeScript
- Realtime: Socket.IO
- Database: PostgreSQL
- ORM: Prisma
- Docker: PostgreSQL через Docker Compose

# Структура проекта

client  — frontend-приложение
server  — backend API + Socket.IO
